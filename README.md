## 🚀 Usage

To use any workflow from this repository:

1. 📥 Clone the repository
2. 📤 Import the `workflow.json` file into your n8n instance
3. 🔑 Configure required credentials and API keys
4. ✅ Adjust workflow settings based on your environment
5. ▶️ Activate and run the workflow
